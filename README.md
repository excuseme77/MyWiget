# Камень: живой виджет для iPhone (без Mac)

Камень сам гуляет по виджету и оглядывается, а от тапа меняет настроение.
Через 20 минут без тапов он засыпает. Нужен iOS 17 или новее.

## Часть 1. Собрать .ipa на GitHub (бесплатно)

1. Зарегистрируйся на github.com.
2. Нажми **New repository**, введи имя `rock-widget`, выбери **Public** (для публичных репозиториев сборка бесплатна без лимитов) и нажми **Create repository**.
3. На странице репозитория нажми ссылку **uploading an existing file**.
   Распакуй архив и перетащи в окно **всё содержимое** папки `RockWidget-project`, включая папку `.github`. Нажми **Commit changes**.
   > Проверь, что в репозитории появился файл `.github/workflows/build.yml`. Если его нет, нажми
   > **Add file → Create new file**, впиши имя `.github/workflows/build.yml`, вставь
   > содержимое этого файла из архива и закоммить.
4. Открой вкладку **Actions**. Если GitHub попросит включить сценарии, включи.
   Сборка запустится сама. Если не запустилась, выбери слева **Build IPA**, затем **Run workflow**.
5. Подожди 5–10 минут, пока не появится зелёная галочка. Открой сборку, внизу в разделе **Artifacts**
   скачай **Rock-ipa** и распакуй: внутри будет `Rock.ipa`.
   - Если появился красный крестик, скачай артефакт **build-log** и пришли его мне.

## Часть 2. Установить на iPhone с Windows

1. Установи **iTunes** и **iCloud** с сайта Apple: нужны версии с сайта, *не* из Microsoft Store.
2. Скачай и установи **Sideloadly** с сайта sideloadly.io.
3. Подключи iPhone кабелем и на телефоне нажми «Доверять этому компьютеру».
4. Перетащи `Rock.ipa` в Sideloadly, введи свой Apple ID и нажми **Start**.
   Затем введи пароль и код двухфакторной проверки.
   (Если не хочешь вводить основной Apple ID, заведи отдельный бесплатный.)
5. На iPhone:
   - **Настройки → Основные → VPN и управление устройством**: выбери свой Apple ID и нажми «Доверять».
   - **Настройки → Конфиденциальность и безопасность → Режим разработчика**: включи его и перезагрузи телефон.
6. Открой приложение «Камень» один раз. Потом зажми пустое место на рабочем столе,
   нажми «Изменить» → «Добавить виджет», найди «Камень» и добавь его.

**Раз в 7 дней** подпись с бесплатного Apple ID истекает, и приложение перестаёт открываться.
Тогда повтори шаг 4: собирать заново не нужно, тот же `Rock.ipa` подойдёт.
В Sideloadly можно включить автопродление по Wi-Fi.

## Что где лежит

- `Widget/RockWidget.swift`: сам камень (рисунок, настроения, движение, тапы)
- `App/RockApp.swift`: экран приложения-контейнера
- `project.yml`: описание проекта (Xcode-проект генерируется из него на сервере)
- `.github/workflows/build.yml`: сценарий сборки на macOS-сервере GitHub

Если поменяешь код прямо на сайте GitHub (иконка карандаша), сборка запустится заново автоматически.
